# 回归 (Regression)

## 一句话定义

> 回归就是从大量的已有数据中**拟合**出一个函数关系，再用它去**预测**未知数据的数值。

## 直观理解

- 拿「带答案的历史数据」去画一条线 / 一个函数
- 然后用这条线去预测新数据的值
- 预测结果是一个**连续数值**（如房价、温度），而不是类别标签 —— 这是回归与分类的区别

## 例子

根据一批「房屋面积 → 成交价」数据，拟合线性关系 h(x) = θ₀ + θ₁x，然后预测新房价格。

## 多输入 / 多元线性回归 (Multivariate Linear Regression)

- 回归的输入也可以是**多个特征**（多输入）
- 如面积、地段、楼层 ⇒ 房价
- 此时拟合的是一个"超平面"：h(x) = θ₀ + θ₁x₁ + θ₂x₂ + …
- **展开式**（n = 特征个数，一个特征配一个权重）：
  ```
  y-hat = w₁x₁ + w₂x₂ + … + wₙxₙ + b
  ```
- **向量化**：特征写成向量 x，权重写成向量 w，则
  ```
  y-hat = wᵀx + b
  ```
- 一句话：输入是多个 → 权重也是多个 → 二者配对写成向量，一步点乘搞定
- **向量化的对象不只 w 和 x**：m 个样本堆成样本矩阵 X，预测值、误差、梯度也都写成矩阵/向量形式批量算
- **软件层**：numpy 等库把循环下沉到 C/Fortran，一次矩阵运算代替逐个循环
- **硬件层**：靠 CPU 多核 / SIMD 并行；更大规模用 GPU（CuPy / PyTorch / TensorFlow），numpy 本身跑 CPU
- **效果**：省训练时间，也省推理/预测时间

## 参数 w 和 b

> w（权重）和 b（偏置/截距）是线性回归模型的两个可学习参数。

- **w**：权重，决定斜率 / 特征重要性；多输入时 w 是向量
- **b**：偏置（截距），允许回归线不经过原点
- 假设函数（预测公式）：
  - 单个输入：`y-hat = f(x) = w·x + b`
  - 多个输入：`y-hat = f(x) = w₁x₁ + w₂x₂ + … + b`（向量写法 `y-hat = wᵀ x + b`）

## 代价函数 J(w, b)（均方误差 MSE）

> 衡量预测值与真实值的差距，值越小越好。

- **Loss（损失函数）**：针对**单个样本**的误差
  ```
  L = (1/2) × (y-hat − y)²
  ```
- **J（代价函数）**：针对**全体 m 个样本**，即所有 Loss 求平均
- 公式（人眼可读版）：
  ```
  J(w, b) = 1/(2m) × Σ (y-hat − y)²
            i=1..m
  ```
  其中：
  - m = 样本总数
  - y-hat = f(x)（预测值）
  - y = 真实值
  - Σ 表示对 m 个样本全部求和
- 为什么要除以 2m：
  - 除以 m：取平均，让代价与样本数无关
  - 除以 2：纯粹为了后续求导时抵消平方导出的 2，公式更整洁

## 回归的目标

> 回归最终的目标就是找到让 J(w, b) 最小（理想为 0）对应的参数 w、b。

- 直观：在所有可能的 w、b 组合里，挑出让"预测误差平方和"最小的那个
- 这正是**梯度下降**要解决的问题 → [[Gradient-Descent]]

## 正规方程 (Normal Equation)

- **一句话**：特征数 n 不大时，一步矩阵运算直接算出最优 w、b，不用迭代
- **公式**（可读版）：
  ```
  w = (XᵀX)⁻¹Xᵀy
  ```
  X = 样本矩阵，y = 真实值向量，一步到位
- **为什么只适合维数不大**：瓶颈是矩阵求逆，复杂度 O(n³)；n 上万就太慢，此时改用梯度下降 → [[Gradient-Descent]]
- **不太通用**：只适用于线性回归这类有解析解的模型
- **库后台用**：sklearn 等成熟库在小规模问题时后台直接调它

## 与分类的区别

- 回归 → 预测**连续数值**（如同一房价、温度）
- 分类 → 输出**有限离散类别**，甚至不是数字 → [[Classification]]
