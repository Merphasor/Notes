# 分类 (Classification)

## 一句话定义

> 分类是从大量已有的数据中学习规则，把新样本分到某个**有限的类别**中。

## 输出特点

- 输出是一个**离散类别**（类标 label），不是连续数值
- 取值范围**很小**，通常就几个类别
- **甚至可能不是数字**，比如 "垃圾邮件 / 正常邮件"、"猫 / 狗 / 鸟"

## 例子

- 垃圾邮件识别：判断一封邮件是"垃圾"还是"正常"
- 图片识别：判断一张图是猫、狗还是鸟

## 决策边界 (Decision Boundary)

- 分类任务常常学到的是拟合一条**决策边界**（直线 / 曲线 / 分面）
- 把样本分成两类，**一侧归一类**
- **由阈值决定**：把预测概率 `p-hat` 与**所选阈值 τ** 比较
  - `p-hat ≥ τ` → 判为 1（正类）
  - `p-hat < τ` → 判为 0（负类）
- **阈值不必是 0.5**，0.5 只是默认值；漏判代价高时可以把阈值调低（如癌症筛查宁可多报）
- **决策边界就是 `p-hat = τ` 的位置**（阈值为 0.5 时即 `z = 0`），把它画在函数图像上
- **边界形状取决于 z 的形式**：z 是直线 → 直线边界；z 里含多项式特征（x²、x₁x₂…）→ 圆形、椭圆等各种曲线边界 → [[Feature-Engineering]]

## 逻辑回归 (Logistic Regression)

> 把线性回归的输出塞进 **Sigmoid 函数**，得到 0~1 之间的概率，用它来做**二分类**。

- **名字的坑**：虽然叫"回归"，其实是**分类**算法（输出的是类别概率）
- **Sigmoid 函数**（也叫逻辑函数 Logistic Function）：
  ```
  g(z) = 1 / (1 + e⁻ᶻ)
  ```
  其中：
  - z = 线性回归那一套 `z = wᵀx + b`
  - e = 自然常数 2.718…
  - 输出永远落在 **0~1** 之间，形状是 S 形
  - z = 0 时 g(0) = 0.5；z 越大越靠近 1，z 越小越靠近 0
- **嵌套方式**：`y-hat = g(wᵀx + b)`
  ```
  z = wᵀx + b        ← 回归部分（算分数）
  p-hat = g(z)       ← Sigmoid 部分（把分数压成概率）
  ```
  - 输出的 `p-hat` 就是**预测为 1（正类）的概率**
  - w、b 是模型自己学的参数：不是先拟合一条回归线再套壳，而是整个 `g(wᵀx + b)` 一起训练
- **例子**：肿瘤大小 → 是恶性肿瘤（1）的概率 = 0.7

## 逻辑回归的代价函数 (Cost Function of Logistic Regression)

> 逻辑回归不能用平方误差当代价函数，要用**对数损失（交叉熵）**，这样才能保证 J 是凸函数。

- **为什么不能套线性回归的 J（平方误差）**
  - 把 `y-hat = g(wᵀx + b)` 代入平方误差后，J 变成**非凸函数**：曲线有很多起伏
  - 结果：梯度下降可能停在**局部最小值**，找不到全局最优
  - **对比**：Sigmoid 是嵌套在里面的，平方误差代进去是一团起伏的曲线；换成对数损失后 J 才变回**凸函数**（碗形），梯度下降不会卡在局部最小值
  - **顺带澄清**：MSE 里那个 1/2 只是为了求导时抵消平方带来的 2；换用对数损失后，公式里本来就没有 1/2 —— 不是"去掉 1/2 才变凸"，凸性是由误差形式决定的
- **先看单个样本的 Loss**（y 只能取 0 或 1）：
  ```
  Loss(w, b) = −y·log(p-hat) − (1−y)·log(1−p-hat)
  ```
  其中：
  - `y` = 真实标签（0 或 1）
  - `p-hat = f(w,b) = g(wᵀx + b)` = 预测为 1 的概率
  - **y = 1 时**：后一项乘 0，`Loss = −log(p-hat)`；预测越接近 1，Loss 越小
  - **y = 0 时**：前一项乘 0，`Loss = −log(1−p-hat)`；预测越接近 0，Loss 越小
  - 一句话：**惩罚"自信地预测错"**，预测对了惩罚趋于 0，错得离谱则 Loss 爆炸
- **整个训练集**（对 m 个样本求平均）：
  ```
  J(w, b) = −1/m × Σ [ y·log(p-hat) + (1−y)·log(1−p-hat) ]
                  i=1..m
  ```
  - 这就是**对数损失（Log Loss）/ 交叉熵（Cross-Entropy）**
  - 相比 MSE：**凸函数**，梯度下降一定能走到全局最小
- **梯度**（推导自己算，可直接用这个结果）：
  ```
  ∂J/∂wⱼ = 1/m × Σ (p-hat − y)·xⱼ
  ∂J/∂b  = 1/m × Σ (p-hat − y)
  ```
  - 向量写法：`∂J/∂w = 1/m × Xᵀ(p-hat − y)`
  - 形式上和线性回归的梯度极像（核心都是「预测值 − 真实值」），**但 `p-hat` 里含 Sigmoid，两者不是一回事**
  - 更新照梯度下降那套：`w := w − α × ∂J/∂w` → [[Gradient-Descent]]

## 与回归的区别

- 回归 → 输出**连续数值**（如房价 ¥520w）→ [[Regression]]
- 分类 → 输出**有限离散类别**（如"猫"），范围小，可能不是数字
