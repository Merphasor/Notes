# 卷积神经网络 (Convolutional Neural Network, CNN)

## 一句话定义

> 除了全连接层，还有一种常用的层叫**卷积层**；用卷积层搭起来的网络就是卷积神经网络。

## 卷积层和全连接层的区别

- **全连接层**：单个神经元接受上一层的**全部**输出
- **卷积层**：单个神经元**只接收上一层的一部分输出**（局部接收）
  - 划法：由**卷积核 (kernel / filter)** 决定，核覆盖的就是一个**局部窗口**
  - 图像里这个窗口就是**空间上邻近的一小片像素**（如 3×3）
  - 不是图像专属：序列数据里窗口就是**相邻的一段时间步**

## 为什么这样设计

- **局部连接**：图像里相邻像素才相关，远处像素关系弱，没必要全连
- **参数共享**：同一个核在整张图上滑动复用，参数量大幅减少
- **感受野 (receptive field)**：这一层一个神经元实际"看到"的输入范围；层数越深，感受野越大
