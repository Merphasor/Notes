# 特征工程 (Feature Engineering)

## 一句话定义

> 通过观察和构造，把原始特征**细化 / 取代 / 组合**，得到性能更好的模型。

## 直观理解

- 模型好不好，一半看算法，一半看特征喂得好不好
- "观察"就是：画图看数据形状、看模型误差和残差规律，再针对性加工特征

## 多项式回归 (Polynomial Regression)

- 把单个特征 x 扩展成 x、x²、x³ 等多项式特征，再做线性回归
- 拟合的是**曲线**，但对参数 w 仍是线性的，所以照样能用正规方程 / 梯度下降解
- 公式（可读版）：
  ```
  y-hat = w₀ + w₁x + w₂x² + w₃x³
  ```
- 例子：房价随面积非线性增长，直线拟合不上，加 x² 项变曲线就贴合了

## 怎么知道要不要加多项式特征

- 没人能提前开天眼知道曲线形状，流程永远是：**简单模型先行 → 观察 → 加特征**
- **画图看**：画 x-y 散点图，点弯成弧线、直线穿过去两边都偏，就是拟合不上
- **看残差**：先用直线试，若误差大且呈现规律（如两头偏高、中间偏低），说明欠拟合，该加高阶项
- **验证集对比**：直线和曲线各训一个，谁在验证集上误差小用谁
