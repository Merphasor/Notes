# 过拟合 (Overfitting)

## 一句话定义

> 过拟合是模型把训练数据（连噪声）记得太死，在新数据上反而变差。

## 三种拟合状态

- **欠拟合 (Underfitting) = 高偏差 (High Bias)**
  - 模型太简单，连训练数据都没拟合好
  - 表现：训练误差大，在新数据上也差
- **刚刚好的模型**
  - 训练误差小，在新数据上也小
  - 这就叫**泛化 (Generalization)：模型对没见过的数据的预测能力**
  - **泛化是机器学习最终的目标**
- **过拟合 (Overfitting) = 高方差 (High Variance)**
  - 模型太复杂，过度迁就训练数据里的每一个点
  - 表现：训练误差极小，但在新数据上很差

## 如何抵抗过拟合

1. **收集更多训练数据**
   - 数据够多时，即便是高阶函数也能拟合得不过分
   - 换句话说：训练集样本数量要和模型复杂度匹配
2. **使用更少的特征**
   - 相对于训练集数据数量来讲，特征太多时就砍掉一部分
3. **正则化 (Regularization)**
   - 一句话：**缩小参数的值**
   - 目的：**保留特征的同时保留特征的影响**，只是把影响调小，而不是把特征删掉
   - **一般只变 w，不变常数项 b**
   - **做法**：由于我们一般不知道哪些权重要、哪些不重要，就**把所有权重一起惩罚** —— 在代价函数末尾加上权重的平方和
     - **正则化后的代价函数**：
       ```
       J(w, b) = 原代价 + (λ / 2m) × Σ wⱼ²
       ```
       其中：
       - λ (Lambda) = **正则化参数**，控制惩罚力度
       - 除以 2m：跟原代价保持同一量纲（m = 样本数）
       - 平方和就是**惩罚项**：想减小 J，就得把 w 一起压小 → 削弱每个权重对输出的影响
     - **对 w 逐项求导后**，更新式变成：
       ```
       wⱼ := wⱼ − α × [ (1/m × Σ (p-hat − y)·xⱼ) + (λ/m) × wⱼ ]
       ```
       直观：**每一步除了按梯度下山，还会额外把 wⱼ 往 0 拉一点**
     - **b 不变**：常数项不进惩罚项，求导结果不变 → `b := b − α × ∂J/∂b`
   - **λ 的选择（两头都不行）**：
     - λ **太小** → 惩罚几乎没意义，照样过拟合
     - λ **太大** → w 被压得接近于 0，模型 `y-hat = wᵀx + b` 约等于常数 b → 接近一条水平直线 → **欠拟合**
