# Softmax 回归 (Softmax Regression)

## 一句话定义

> Softmax 回归是**逻辑回归的泛化**：从"二分类"扩展到"多分类"，输出每个类别的概率。

## 函数

```
zⱼ = wⱼᵀx + bⱼ                （每个类别 j 各算一个线性得分）
aⱼ = softmax(z)ⱼ = e^(zⱼ) / Σₖ e^(zₖ)     （k 遍历所有类别）
```
- 分子：把自己那一类的得分取指数
- 分母：**所有类别**得分指数的和（做归一化）
- 结果：每个 aⱼ 都在 0~1，且**所有类别加起来等于 1** —— 所以它输出的是一个**概率分布**
- 对比逻辑回归：只有 1 个输出 + Sigmoid；Softmax 有 C 个输出，互相"抢"概率

## Loss（单个样本）

- 真实类别记作 y（取值 1…C），**只给真实那一类算损失**：
  ```
  Loss = −log(a_y)
  ```
  - a_y = 模型给**真实类别**预测的概率
  - **输出越接近 1 → log 越接近 0 → 损失越小**；越接近 0 → 损失爆炸
  - 和逻辑回归的对数损失同源：其他类别因为 y 为 0，乘出来是 0，自然不参与
- 如果写成 one-hot 形式（yⱼ 只在真实类为 1）：
  ```
  Loss = −Σⱼ yⱼ · log(aⱼ)
  ```

## Cost（整个训练集）

```
J = −1/m × Σᵢ Σⱼ yᵢⱼ · log(aᵢⱼ)        （i 遍历样本，j 遍历类别）
```
- 就是对 m 个样本的 Loss 求平均
- 也叫**交叉熵 (Cross-Entropy)**

## 在神经网络里的实现要点

- **这一层的每个输出，要用当前层的全部去激活输出（z）来算**（因为分母要所有类别的指数和）—— 这点和别的层不同：别的层每个神经元各算各的，Softmax 的这一层是**互相耦合**的
- **数值稳定性**：计算机浮点数精度有限，**不要自己先 softmax 再算 log**（先指数再取对数，中间结果容易溢出 / 丢精度）
  - **通用原则**：把「对数 + Softmax + 交叉熵」当成**一个整体**交给框架的**融合算子**
    - **算子 (Operator/Op)**：框架里一个封装好的基本运算单元（如矩阵乘法、加法、Sigmoid、Softmax 都是算子）；**融合算子**就是把几步合成一步、内部用更稳的算法一次算完
  - 因此写法是：**这一层只输出去激活输出（z，也叫 logits），等到要取结果时再套一层 Softmax**
- 一句话：**训练时喂 logits 给框架的融合损失；只有看最终概率时才单独调 Softmax**

## 多标签分类 vs 多类分类

- **多类分类 (Multi-class)**：一个输入**只属于一个**类别 → 输出互斥，用 Softmax（概率和为 1）
- **多标签分类 (Multi-label)**：一个输入**可以同时有多个标签**（如一张图同时有"人"和"车"）→ 各标签**互不排斥**
  - 输出是**每个标签各自是否存在的判断**，不是"选一个"
  - 做法上通常对每个标签各用一次 **Sigmoid**（二分类），而非 Softmax
