# 梯度下降 (Gradient Descent)

## 一句话定义

> 为找到最小的 J，先猜一组参数初值，再沿负梯度方向一步步走，直到 J 最小。

## 直观理解（下山比喻）

- 从猜测的起点出发，沿**最陡的下山方向**走一小步，重复此过程直到到达山谷
- 更正：不是真的"绕 360° 试探"，数学上是**直接算偏导数得到方向**
- 最陡下山方向 = **负梯度方向 −∇J**
- **不同起点可能落到不同的山谷 → 局部最小值**（vs 全局最小值）

## 导数 vs 梯度

- 对**单个参数**用的是**偏导数**，如 ∂J/∂w、∂J/∂b
- 所有参数的偏导数组成的向量才叫**梯度**：∇J = [∂J/∂w, ∂J/∂b]
- **梯度为零向量 ⇔ 每个偏导数都为零 ⇔ 到达（局部）最小**

## 参数更新公式

```
w := w − α × ∂J/∂w
b := b − α × ∂J/∂b
```

- 下山的方向就是 J 对参数求偏导
- 下山的步子大小就是**学习率 α**

## 学习率 α (Learning Rate)

- 用符号 **α** 表示，典型取值在 0~1 之间（如 0.01、0.1）
- **α 太小**：收敛得慢
- **α 太大**：容易错过最小值，甚至发散
- **调试技巧**：按约 3 倍递增试一串 α（如 0.001、0.003、0.01、0.03、0.1、0.3、1），画学习曲线观察；最终选比测得最优值略小一点的 α

## 越接近目标，步子自动变小

- 越接近最小值，斜率越小、偏导数越小
- 直到偏导数为零，即到达（局部）最小值
- 也就是说：**越接近目标值，参数的变化会自动变得越来越小**

## 同步更新注意

- 计算时先用 temp_w、temp_b 存储新的参数值，**最后统一赋值**
- 否则会出现"部分参数已用新值、部分还是旧值"的混用错误

## 批梯度下降 (Batch Gradient Descent)

- **一句话**：每走一步，都用**全部 m 个样本**算梯度
- 其实前面讲的更新公式默认就是批梯度下降（J 里那个 Σ 是对全部样本求和）
- **特点**：方向准、稳定；但样本很多时，每步都要扫全量数据，比较慢

## 备注：线性回归的特殊情况

- 上述"不同起点 → 不同山谷"是对一般函数成立
- 但**线性回归的 J 是碗形（凸函数），只有一个全局最小值，起点不影响结果**

## 判断收敛与正确运行

- **学习曲线 (Learning Curve)**：横轴迭代次数、纵轴 J 的曲线；正常应单调下降并**趋平**，趋平即收敛
- **自动收敛测试**：若一次迭代 J 的减小量 < ε（如 1e-3），判定收敛；ε 不好选，实践中多直接看曲线
- **排错技巧**：用极小 α 跑一次；若 J 仍不下降 → 代码有 bug；若下降 → 原来是 α 的问题
