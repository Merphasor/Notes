# 神经网络 (Neural Network)

## 一句话定义

> 神经网络是把很多个"神经元"一层层叠起来：每个神经元对上一层的输出做一次「加权求和 + 激活函数」的运算，得出下一层的向量元素。

## 直观理解（需求预测例子）

- **输入层**：4 个特征 → 4 个数字（price 价格、shipping cost 运费、marketing 营销费、material 材料成本）
- **隐藏层 (hidden layer)**：一层里可以有**多个神经元 (neuron)**，这个例子里是 3 个
  - 每个神经元自己学出一个**中间概念**：affordability（买得起吗）、awareness（知名度）、perceived quality（感知质量）
  - 这些中间概念就是这一层的**激活值 (activations)**
- **输出层 (output layer)**：1 个神经元 → 输出 1 个数字
  - 这里输出的是「成为爆款的概率」，也就是最终要的预测
- 每经过一层，数字个数都会变：**4 个数字 → 3 个数字 → 1 个数字**

## 每个神经元在做什么（激活公式）

```
aⱼ⁽ˡ⁾ = g( wⱼ⁽ˡ⁾ · a⁽ˡ⁻¹⁾ + bⱼ⁽ˡ⁾ )
```
其中：
- `aⱼ⁽ˡ⁾` = 第 l 层、第 j 个神经元（单元 unit）的**激活值**（它输出的那个数字）
- `a⁽ˡ⁻¹⁾` = **上一层（第 l−1 层）的输出**，作为这一层的输入
- `wⱼ⁽ˡ⁾`、`bⱼ⁽ˡ⁾` = 第 l 层第 j 个神经元的**参数**（权重 w 和偏置 b）
- `g` = **激活函数 (activation function)**，这里用的是 **Sigmoid**
- 一句话：**每个神经元把上一层的输出与自己的一组权重做运算，得到下一层的一个向量元素**
- **关键**：`a⁽ˡ⁻¹⁾` 是**向量**（上一层的所有激活值），`wⱼ⁽ˡ⁾` 也是**向量**（这个神经元对应每个输入的各一个权重），两者中间的 `·` 就是**向量点乘**（逐项相乘再相加），再加上一个标量偏置 `bⱼ⁽ˡ⁾`
  - 点乘的前提：**两个向量元素个数相同**，所以 `wⱼ⁽ˡ⁾` 的长度 = 上一层激活值的个数

## 一层怎么算（矩阵形式）

- 上一层的每个输出，都连到这一层的**每一个**神经元（每个神经元都用上一层的**全部**输入，这就是"全连接"）
- 输入 4 个数字 → 隐藏层 3 个神经元 → 得到 3 个数字，写法是：
  ```
  z = W · a_prev + b_vec        （W 是权重矩阵，a_prev 是上一层激活向量，b_vec 是偏置向量）
  a = g(z)                      （对向量每个元素分别做 Sigmoid）
  ```
- 以「4 个输入 → 3 个神经元」为例：
  ```
  [ z₁ ]   [ w₁₁ w₁₂ w₁₃ w₁₄ ] [ x₁ ]   [ b₁ ]
  [ z₂ ] = [ w₂₁ w₂₂ w₂₃ w₂₄ ] [ x₂ ] + [ b₂ ]
  [ z₃ ]   [ w₃₁ w₃₂ w₃₃ w₃₄ ] [ x₃ ]   [ b₃ ]
                                [ x₄ ]
  ```
- **矩阵的行数 = 这一层的神经元个数**，列数 = 上一层元素个数
  - 所以**输出元素的个数由神经元个数决定**，跟"每个神经元吃几个输入"无关
  - 想从 4 个压到 3 个 → 放 3 行；想从 4 个扩到 10 个 → 放 10 行
  - 元素变少不等于丢了某个特征，而是上一层信息被**重新加权组合**了
- **参数共享**：
  - **同一个神经元**：只有**一组** w 向量 + 1 个 b，处理它的所有输入都用这一组
  - **同一层不同神经元**：权重**各自独立**，互不共享
  - **不同样本之间**：共享同一套参数（模型训练完就固定了）

## 和特征工程的区别

- **特征工程**：需要**人工**观察数据、手工构造特征
- **神经网络**：**不需要人工为每一层选择对应的输入特征，它会自己学习**
- 但**网络结构仍要人工决定**：隐藏层的**个数**、每层里**神经元的个数**
- 这种多层结构，一些文献称为**多层感知机 (Multi-layer Perceptron, MLP)**

## 激活函数 (Activation Function) 为什么需要

- 每个神经元最后那一步 `g(...)` 就是**激活函数**
- **核心原因**：如果**不加**激活函数，多层叠加就会**坍缩成一层**
  - 因为线性函数套线性函数，结果还是线性的（多个线性函数相加 / 复合还是线性）
  - 那样堆再多隐藏层，整个网络也等价于**一个线性模型**，层数白搭
  - 所以每层之间必须插入**非线性**的激活函数，网络才能拟合复杂形状

## 常用激活函数

- **Sigmoid**
  - 把值压到 0~1 之间
  - 用途：**二分类**的输出层（输出概率）
- **ReLU (Rectified Linear Unit)**
  - 公式：
    ```
    ReLU(z) = max(0, z)
    ```
    - z > 0 → 原样输出 z
    - z ≤ 0 → 输出 0
  - 结果**非负**（小于 0 的部分一律取 0，大于 0 的部分原样输出）
  - **计算快**，所以**隐藏层最常用**
- **线性激活函数（即不加激活函数）**
  - 输出**有正有负**，不改变数值范围
  - 一般用在不需要限制输出范围的场合（如回归的输出层）
- 其他激活函数后续补充

## 前向传播 (Forward Propagation)

- 从输入层开始，一层一层往后算激活值，直到算出输出层的预测值 —— 这个过程叫**前向传播**
- 方向和"学参数"的过程相反：这里只做"算"，不做"学"

## 张量 (Tensor)

- **张量 = 多维数组的统称**，比矩阵更通用：
  - 0 维：标量（一个数）
  - 1 维：向量
  - 2 维：矩阵
  - 3 维及以上：更高阶张量（如一批彩色图片：批大小 × 高 × 宽 × 通道）
- 一句话：**张量是矩阵向更高维度的推广**；前面写的 `a`、`w`、`W` 都是张量（低维特例）
- NumPy 的 `ndarray` 本身也支持任意维度，两者同属"多维数组"这一族

### 与 NumPy array 的不一致

- **不能当同一个东西随便混用**：把 NumPy 数组丢给只收张量的操作（或反过来），常常报错，**需要显式转换**
