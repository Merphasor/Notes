# 非监督学习 (Unsupervised Learning)

## 一句话定义

> 非监督学习从**无标签**的数据中自行发现结构和规律，不需要"正确答案"。

注释：与监督学习的区别在于——监督学习需要"带答案"的样本，而非监督完全凭空在数据里找规律。

## 三大任务

### 聚类 (Clustering)

- 按**相似度**把样本自动分组成一个个**簇**（cluster）
- 更正：口语里说的"簇 / 族"就是 cluster；注意不是"分类"，聚类没有预定义标签，靠数据相似度自己分组
- 例子：新闻自动分主题、顾客分群

### 异常检测 (Anomaly Detection)

- 识别出跟大多数数据**很不一样**的样本
- 例子：信用卡欺诈交易、服务器异常流量

### 降维 (Dimensionality Reduction)

- 把很多特征压缩成**更少的关键特征 / 维度**，同时也可能保留对数据原有规律的描述
- 例子：图像压缩

## 与监督学习的对比

- 监督学习：有标签（带答案），学习 x → y → [[Supervised-Learning]]
- 非监督学习：无标签，自己找规律
